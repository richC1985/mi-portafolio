## ✨ Características Técnicas
- **HTML5 Semántico:** Estructura accesible validada bajo el estándar W3C.
- **CSS3 Moderno:** Arquitectura modular basada en variables CSS (`custom properties`), maquetación híbrida con Flexbox y CSS Grid, y diseño Responsive Mobile-First.
- **JavaScript ES6+ Vanilla:** Menú responsive, alternador de modo oscuro (Dark Mode) con persistencia en `localStorage`, navegación suave y validación de formulario.
- **Accesibilidad & Performance:** Cumple con criterios WCAG (Skip-links, estados de foco visibles y etiquetas ARIA).

## 🛠️ Tecnologías Utilizadas

- JavaScript Vanilla (ES6+)
